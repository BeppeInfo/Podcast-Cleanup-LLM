Not on this page

Three kinds of setting are deliberately absent. Paths are how the container is wired to its volume, and a page that could rewrite them could write anywhere. Filename conventions are unnecessary here — the upload form asks for the episode and each participant and writes the names itself. API keys would be stored in clear on the volume; set them in the environment, or point the _FILE variants at a file you control.

Only settings you have changed are stored. Anything untouched keeps following the built-in default, so a later version with better defaults still reaches you.
